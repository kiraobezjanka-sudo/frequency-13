# Частота 13: Последний эфир

![Зависимости](https://img.shields.io/badge/зависимости-нет-2b8a6f?style=flat-square)

Интерактивная история о двух незнакомцах, которые пытаются зажечь старый маяк до прихода прилива.

Лада — инженер, оставшаяся в башне после прошлой катастрофы. Север — курьер, который несёт через затопленный город последнюю синюю катушку. Игрок выбирает их реплики и решает, какой сигнал услышит город.

## Что нужно сделать

Проведите Ладу и Севера через пять разговоров, сохраните связь и успейте запустить маяк. Итог зависит от доверия между героями, силы сигнала, оставшегося времени, катушки и признания Севера.

Перед первым выбором игра показывает короткую предысторию из трёх кадров — она объясняет, почему маяк погас и что поставлено на карту этой ночью.

## Управление

| Действие | Управление |
| --- | --- |
| Выбрать реплику | `1`–`3` или нажать на вариант |
| Начать игру / листать предысторию / продолжить | `Space` или экранная кнопка |
| Поставить на паузу | `Escape` |
| Начать заново | `R` или кнопка «Начать заново» |

Игра адаптирована для мыши, сенсорного экрана, клавиатуры и узких мобильных экранов. Для тех, кому некомфортна анимация, учитывается настройка `prefers-reduced-motion`.

## Как запустить

Не нужны ни сервер, ни зависимости: можно просто открыть `index.html` в современном браузере.

Для локальной разработки:

```powershell
npm run build
python -m http.server 4173 --directory dist
```

Затем откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

```powershell

```
