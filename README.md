# Частота 13: Последний эфир

Короткая атмосферная игра с выбором реплик. Трёхкадровая предыстория объясняет катастрофу маяка, прорыв дамбы и задачу героев. Затем Лада, инженер заброшенного маяка, и Север, курьер затопленных улиц, впервые слышат друг друга по радио. За пять решений игрок определяет, смогут ли они запустить маяк и какую правду услышит город.

## Как играть

Откройте `index.html` в современном браузере или запустите локальный статический сервер. Выбирайте реплики мышью/касанием или клавишами `1`–`3`. `Escape` ставит игру на паузу, `R` начинает историю заново.

В игре четыре концовки. На них влияют доверие, качество сигнала, оставшееся время и решения, принятые у двери маяка.
